Each heading is a study, taken about the attitude of the calm-water study at its speed (queued too, if it is not already). 180° is head seas, 90° beam, 0° following.

Transom closure and resolution

The ballistic hollow is Lv = c·U·√(dT/g), c = √2 by default. The default closure uses it while the transom is wet and a fraction of the transverse wavelength 2πU²/g once it runs dry, blending between them for transom Froude numbers U/√(g·dT) from 2.5 to 3.5. The grid sets the calm-water wave pattern's resolution only; resistance and attitude do not depend on it.

Speeds and headings take a value, a list (6, 8) or a range (4:8:0.5); every study goes on every case ticked. Studies already asked for are not asked for again.
